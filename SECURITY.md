# Security policy

HonoKit for Android opens files from anywhere: a PDF or picture someone sends you should never be
able to harm your phone, read your other files, or reach the internet behind your back. If you find
a way it can, please tell us privately.

## Reporting a vulnerability

- Use GitHub's **private vulnerability reporting**: on this repository, open the **Security** tab
  and choose **Report a vulnerability**
  ([direct link](https://github.com/abd-el-rahman-mustafa/HonoKit-Android/security/advisories/new)).
- **Do not** open a public issue, pull request or discussion about it.
- Include the HonoKit version (Settings › About), your Android version, what an attacker could do,
  and the steps or a test file that shows it (made for the purpose, with nothing private in it).

You will get an answer as soon as possible. Once a fix is released, the advisory is published
with credit to you, unless you prefer otherwise.

## Supported versions

Only the newest release on
[HonoKit-Releases](https://github.com/abd-el-rahman-mustafa/HonoKit-Releases/releases)
(tags `android-v…`) gets security fixes. Installed copies update themselves from there.

## Scope

In scope: the app in this repository, including how it reads PDFs and pictures, the files it
writes, links in documents and the update check. Problems in MuPDF or another library are welcome
too; they will be passed on upstream.
